# Курсовая работа: Игра-кликер «Мой карасик»

## Описание

Смысл игры — нажимать по карасику и зарабатывать коины в виде червячков.
В игре есть магазин, где можно за коины покупать шляпы на карася, а также уровни (звания).

---

## Технологии

- **Язык**: C# (.NET 10.0)
- **UI**: WPF (Windows Presentation Foundation)
- **Авторизация**: HTTP API (регистрация / вход)
- **Сохранение**: HTTP API (автосохранение каждые 30 секунд)
- **Графика**: PNG-изображения из папки `assets/`

## Классы (ООП)

### `Rank` — Звание
- `Name` — название звания
- `ClicksPerHit` — сколько червячков даёт 1 клик на этом ранге
- `RequiredCurrency` — сколько нужно червячков для перехода на этот ранг

### `Crucian` — Карась
- `CurrentRankIndex` — индекс текущего ранга
- `Currency` — текущее количество червячков
- `EquippedHat` — надетая шляпа (может быть null)
- `TotalClicks` — всего кликов за игру
- `Click()` — возвращает заработок за один клик
- `TryRankUp()` — проверяет и повышает ранг

### `Hat` — Шляпа
- `Name` — название шляпы
- `Price` — цена в червячках
- `Multiplier` — множитель заработка
- `ImagePath` — путь к PNG

### `Shop` — Магазин
- `AvailableHats` — список всех шляп
- `TryBuy(Hat, Crucian)` — покупка шляпы
- `Equip(Hat, Crucian)` — надевание шляпы

### `GameManager` — Управление игрой
- `Crucian` — текущий карась
- `Shop` — магазин
- `HandleClick()` — обработка клика
- `BuyHat(int)` — покупка шляпы
- `EquipHat(int)` — надевание/снятие шляпы
- `SaveGame()` / `SaveOnExit()` — сохранение на сервер
- `StartNewOrLoadGame()` — загрузка с сервера при старте

### `SaveManager` — Сохранение
- `Save(Crucian)` — отправляет прогресс на сервер через ApiClient
- `Load(Crucian)` — загружает прогресс с сервера через ApiClient

## Сохранение (HTTP API)

Прогресс сохраняется на сервер через POST `/api/auth/saveUserData`.

События сохранения:
- **Автосохранение**: каждые 30 секунд (если были изменения)
- **При повышении ранга**: мгновенно
- **При покупке/надевании шляпы**: мгновенно
- **При закрытии окна**: `SaveOnExit()`

Загрузка прогресса при запуске игры через POST `/api/auth/loadUserData`.
Если данных на сервере нет — начинается новая игра.
